# Dream Catcher · predlog sajta

Demo sajt za kasačku štalu Dream Catcher iz Sombora. Statičan sajt: `index.html` + `assets/`, bez build koraka.

- Lokalni pregled sa skrol videom: `npx http-server` u ovom folderu (dupli klik na index.html prikazuje statičnu sliku umesto videa).
- Vercel: uvezi repo, Framework Preset "Other", bez build komande, Output Directory prazan.
- Mesta označena sa „(proveriti)“ čekaju potvrdu podataka od vlasnika.
